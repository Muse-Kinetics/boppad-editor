###Release Notes for this version


Version 1.3.0

- Fixed the editor going blank after clicking between fields, or when a BopPad is plugged in
- User tables: save your own curves on your computer and edit them without a BopPad connected
- User tables: one curve menu with your saved curves and the BopPad's four tables, plus destination buttons to send a curve to any slot
- User tables: import and export your saved curves as a file
- Mac: fixed buttons and labels that couldn't be clicked, including Keyboard (show) and the quadrant headers
- Mac: fixed Check for Updates


Version 1.2.0

- Rebuilt on a single modern shared codebase between the web and desktop editors (Electron 28, Node 24)
- Firmware updates are now sent in verified packets instead of one large transfer, for more reliable flashing
- Firmware version 3.0.4
- Windows: added Help > Install Windows MIDI Services


Version 1.1.0

- MIDI Thru
- Device-related UI disbaled if device not connected
- restructured preferences window


Version 1.0.0

- Preset Naming
- Firmware version 3.0.0
- Latest Electron
